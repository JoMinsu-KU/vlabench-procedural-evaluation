# Editorial provenance

These files document the manuscript's estimand, claim boundaries, and terminology. They are editorial records rather than experimental evidence.

- `claim_matrix/provisional_claim_matrix.md` records the boundaries adopted before the registry and composition audits.
- `claim_matrix/final_claim_matrix.md` records the boundaries retained after those audits.
- `terminology_glossary/terminology_glossary.md` maps artifact field names to manuscript-facing terms.

The reproducibility evidence itself is stored under `reproducibility_core/`.
