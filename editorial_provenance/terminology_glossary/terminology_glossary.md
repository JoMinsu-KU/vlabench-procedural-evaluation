# v1.2 manuscript terminology glossary

| Concept | Preferred term | Notes / prohibited alternatives |
|---|---|---|
| Experiment A | **high-level symbolic planning interface**; on first definition, **official-style high-level symbolic planning interface** | Do not call it the complete official baseline unless every protocol detail is identical. |
| Experiment B | **benchmark-derived reference-procedure planning interface** | `execution-grounded` may be a secondary modifier, not the primary name. Avoid `low-level planning/control`. |
| Experiment-B endpoint | **first-attempt reference-procedure task success** | Replace ambiguous `procedural success` when referring to the measured endpoint. |
| Full B | **full reference-procedure condition (Full B)** | Expand at first use. |
| Phase-oracle artifact condition | **reference-phase scaffold** | At first use: “reference-phase scaffold (artifact name: Phase-oracle).” |
| Target-oracle artifact condition | **reference-target scaffold** | At first use: “reference-target scaffold (artifact name: Target-oracle).” |
| Main method contribution | **planning-responsibility reallocation** | Discrete procedural responsibilities only; not VLABench architecture redesign. |
| Main empirical relationship | **model–case-level cross-interface discordance** | Outputs are independently elicited. Avoid same-plan degradation/transfer failure. |
| Granularity gap | **planning–execution granularity gap**, defined as cross-interface discordance | Use sparingly and define once; it is not a same-plan transformation gap. |
| Reference procedure | **fixed benchmark-derived reference-procedure contract** | Avoid `canonical` except when quoting legacy filenames/code. Does not mean unique physical solution. |
| Scaffold result | **scaffold-conditioned aggregate outcome change/recovery** | Avoid causal recovery, repair, decomposition, or bottleneck attribution. |
| Failure result | **responsibility-adjudicated first-termination taxonomy** | Keep distinct from observed runtime taxonomy and latent error prevalence. |
| Corrected gate | **offline corrected-gate revalidation**; **rejection-only refinement** | Never imply original runtime rerun. |
| Bootstrap | **95% task-cluster bootstrap sensitivity interval** | Avoid unseen-task population inference. |
| Case set | **fixed analysis manifest**; **dual-replay-qualified subset** | Avoid `fixed case population`, `stable benchmark subset`, or `reliable execution subset`. |
| Positive control rate | **observed first-attempt positive-control success rate** | Avoid theoretical `execution ceiling`. |
